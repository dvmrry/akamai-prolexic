# prolexic v0.1.0

The first release. `prolexic` is a command-line client for Akamai Prolexic, over the Akamai APIs. It is unofficial: not affiliated with or endorsed by Akamai.

## What's in it

- **Network Cloud Firewall alias entries as reviewed desired state.** A JSON file in git is the intent. `plan` diffs it against live, `apply` writes the reviewed plan and nothing else, and `verify` reads the result back. `export` starts or updates the file from live, and `add`, `remove` and `fmt` keep it canonical. A plan refuses a deny entry that covers your own address space.
- **Read-only visibility across Prolexic:** firewall aliases, ACLs and rule hits; Routed BGP sessions, routes and tunnel health; attacks, events and traffic; Network Health targets.
- **An MCP front for local agents.** `prolexic mcp` offers the operations as tools over stdio, with no listener and no network transport. It reads live state and edits local files. It has no apply and refuses write credentials, so changes reach the firewall through version control.
- **Documents, not screen scraping.** Every command prints one JSON document with a published schema, or text on request, and exit codes say what happened.

## Status

- Only the read side has run against a live account so far. `apply` has been tested against an in-memory model and a fake API, and has not yet written to a live account. Start with `plan` and `verify`.
- Before 1.0, a minor release can change commands, output and the desired file format.

## Install

Archives for Linux, macOS and Windows (amd64, arm64) are attached, with SBOMs, signed checksums and build provenance. The [README](https://github.com/dvmrry/akamai-prolexic/blob/v0.1.0/README.md#install) says how to verify them, and which API access each command needs.
