## prolexic fmt

rewrite the desired file in canonical form, or --check it (offline)

```
prolexic fmt [flags]
```

### Options

```
      --check         fail if the file isn't canonical; write nothing
      --file string   the desired file (required)
  -h, --help          help for fmt
```
