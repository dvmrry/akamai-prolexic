# spec/

Local copies of Akamai OpenAPI specs that are only available behind the
Akamai login (techdocs / Control Center). Everything in this folder except
this README is gitignored: the specs are downloaded under Akamai's portal
terms and must never be committed, because this repo may go public.

Code written or generated from a spec is ours and is committed as usual.

Specs Akamai publishes openly (github.com/akamai/akamai-apis, Apache-2.0)
don't belong here; vendor those elsewhere with their license and a pinned
commit.
